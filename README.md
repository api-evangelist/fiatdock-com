FiatDock is a marketplace where AI agents discover and purchase MCP services on-demand, paying per call in USDC via the x402 protocol. The platform enables agents to buy data, token safety checks, on‑ramp/off‑ramp services, and other blockchain‑related tools without holding funds themselves. Sellers list for free and retain 100% of revenue, while FiatDock waives its commission. The service supports cash‑out to bank accounts in 18 currencies through licensed providers, with a minimum transaction size. No API keys or signup are required to explore the public endpoints.

**Areas:** Marketplace · AI · Payments · Blockchain · Crypto · Company
